# 🛒 AI Shopping Assistant

An AI-powered shopping assistant built using Flowise and OpenRouter API.

## 📌 Description

This assistant recommends products based on user needs and budget. It suggests 3 products with price and a short reason.

## 🚀 Features

* Budget-based recommendations
* Simple conversational AI
* Fast responses

## 🧠 How It Works

User Input → Prompt → LLM (OpenRouter) → Output

## 🛠️ Tech Stack

* Flowise
* OpenRouter API
* Mixtral Model

## 📂 Files Included

* Chatflow JSON
* Project Report (PDF)

## ▶️ How to Run

1. Import the JSON file into Flowise
2. Add your OpenRouter API key
3. Run the chat
